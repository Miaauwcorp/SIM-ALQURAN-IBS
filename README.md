# SIM MUROJAAH IBS RIAU

SIM Murojaah IBS Riau adalah sistem informasi manajemen berbasis web dengan Progressive Web App yang digunakan untuk mencatat, memantau, dan mengevaluasi kegiatan murojaah santri di IBS Riau. Sistem ini menggantikan pencatatan manual yang biasanya dangat mudah dicurangi dalam prosesnya. Dengan Sistem yang terpusat, rapi, dan mudah diakses, diharapkan agar Pilar Al-Qur'an IBS Riau dapat berjalan dengan mutunya yang terjamin

Melalui sistem ini, ustadz/ustadzah dapat menginput setoran murojaah harian santri (surah, juz, ayat, jumlah halaman, dan nilai/kualitas bacaan), sehingga progres setiap santri terpantau secara berkelanjutan. PJ AL-Qur'an sebagai pengawas harian juga bisa melihat rekap dan laporan perkembangan hafalan per santri, per kelas, maupun per Rombel. Wali santri juga dapat memantau perkembangan anaknya melalui Portal santri terintegrasi di web https://santri.miaauwcorp.my.id/
